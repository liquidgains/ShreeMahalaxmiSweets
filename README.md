# Sweet Shop Website

A premium website designed for a traditional Indian sweet shop, showcasing products, festival collections, and brand identity through a modern digital experience.

![Preview](assets/preview.png)

---

## Overview

This project modernizes the online presence of a local sweet shop while preserving its traditional identity.

The website emphasizes visual storytelling, responsive layouts, and a customer-friendly browsing experience.

---

## Features

- Responsive Design
- Product Showcase
- Festival Specials
- Brand Story
- Customer Testimonials
- Gallery
- Contact Section
- Smooth Navigation
- Mobile Optimized

---

## Design Goals

- Blend tradition with modern UI
- Increase customer engagement
- Improve product discoverability
- Encourage store visits
- Build trust

---

- HTML5
- CSS3
- JavaScript
